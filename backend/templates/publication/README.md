# 公示时长库版式模板

参考用户提供的 `26-27年9月时长库.zip`，保留13个学院、68个工作表的名称、顺序、表头、表头样式、数据行样式、列宽、行高、有效条件格式、数据验证、筛选按钮和打印设置。原包及各工作簿的SHA256、模板文件SHA256和逐页表头记录在 `manifest.json`。

这些文件只包含版式，不含学生记录。提取时仅保留表头和一行空白数据行样式，移除原始共享字符串、学生单元格及其公式、备注批注、超链接、绘图、外部链接及文档属性。超出有效表头的膨胀空白列不保留。筛选按钮保留，旧数据筛选条件清空，运行时调整范围以覆盖全部导出学生。

原包有5处无效打印标题，内容为个人姓名文字，不能作为打印区域；另有1条条件格式使用失效的 `#REF!` 引用。这6处异常元数据不进入模板，清理数量记入 `manifest.json`，原文件保持不变。

另有2条旧条件格式携带完整学号格式的固定数值，不属于通用版式，已移除并记录。回归会扫描模板所有ZIP部件，确认元数据中没有遗留学号常量。

运行时直接填充模板内的工作表XML，保留原有样式与打印设置，避免Excel库重新序列化时改变格式。ExcelJS只用于生成原表无“备注”列时需要的批注部件。导出按已发布快照生成，不读取当前审核库的身份或联系方式。

模板没有的新年级沿用同学院已有页的版式，新建相应年级页；会计学院、数学科学学院、管理学院没有独立参考表，沿用计算机学院模板，填写各自学院的数据。

修改模板后需更新摘要并运行 `npm --prefix backend run test:publication-export`，该检查只允许连接专用隔离数据库。
