# 管理员导出公示Excel

状态：管理员公示导出已上线；2026-10-19按用户澄清修正历史分类，生产核验见[历史分类恢复记录](历史分类恢复_2026-10-19.md)。

## 使用方法

1. 使用“管理员”或“超级管理员”账号登录管理后台。
2. 打开“统一发布”，在当前公示信息下点击“导出当前公示Excel（ZIP）”。
3. 等待生成并下载压缩包。需要旧版本时，在“发布记录”找到对应行，点击“导出Excel（ZIP）”。
4. 解压后按学院查看Excel工作簿，在工作簿内查看相应年级页。

导出读取所选已发布版本。办公室仍在审核、已有通过记录尚未统一发布、或者后续修改了学生信息时，都不会改变已选版本的导出内容。导出不要求全库待审数为0，也不会触发新的统一发布。

## 压缩包和表格格式

- 压缩包及其中目录使用 `XX-XX年X月时长库` 命名；月份取所选公示版本的“公示月份”，学年按该版本保存的学年起始月份计算。
- 学院工作簿沿用参考包的命名，文件名中的 `9.20` 改为对应的 `X月公示`。
- 原13个学院逐一使用各自参考表，保留原工作表名称、排列顺序、表头文字、样式、列宽、行高、有效条件格式、数据验证、筛选按钮和打印设置。不把“本科25级”“研25级”“25级”等不同页面混为一页。筛选范围覆盖本次全部导出行。
- 原表没有的新年级，沿用本学院相应类别的页面样式追加工作表。无法确定的年级放在“年级待核对”页，年级单元格保留公示中的原值。
- 经济金融学院原表只有一个工作表，继续使用其单页结构。
- 会计学院、数学科学学院、管理学院在参考包中没有独立模板，使用计算机学院的页面结构，填写各自学院的数据。
- 各页按学生累计时长降序排列，同分时按学号、姓名稳定排序。学号保存为文本，时长保存为数值。

## 历史明细与缺失字段

“服务时长（小时）”是该学生在所选公示中的正式累计，包含已发布的正负校准，不把累计校准重复算成新活动。

具体发生日期与原表分类分别保存。原表明确的学年、上半年、下半年和寒暑假分类必须保留，日期为空也写入对应活动列。只写“补录寒暑假”而未写学年的明细，写入不带学年的寒暑假列，不猜测学年。原表未提供分类，或模板没有该学年阶段栏目时，在备注中保留原分类说明，不挪到另一学年或阶段。重庆知识产权学院“研25级”原表没有备注列，该页的历史明细写在总时长单元格批注中，保持原表头不变。

“性别”“联系方式/电话”等列保持原位置。当前公示快照没有保存的值留空，不从未发布的审核库补入。

原表行高保持不变，部分历史备注较长。查看完整内容时，可选中备注查看Excel编辑栏，或手动展开对应行高。

参考原文件中5处打印标题填写成姓名文字，另有1条条件格式引用失效。导出模板清除了这6处无效元数据，保留其他有效规则；原文件不修改，清理数量已记录。

另移除了2条含原始学号格式常量的固定值条件规则，避免把旧学生数据留在版式文件中。通用的重复值配色、色阶等规则继续保留。

同一学号对应不同姓名时，按公示中的“学号＋姓名”分别导出，不凭同名或同号自动合并。学生的学院和年级采用该公示版本内最新非空资料，与正式查询汇总口径一致。

如果单元格明细超出Excel长度限制或含有Excel不支持的控制字符，导出会提示具体问题，不截断后继续生成。

## 权限与审计

只有管理员和超级管理员拥有此功能。数据管理员、学院管理员、活动组织者、只读审计员及未登录使用者均不能下载。

每次成功导出记录公示版本、记录数、学生汇总数、学院文件数和使用参考模板的学院，供“操作日志”回查。业务记录、公示指针和数据版本不因导出改变。
